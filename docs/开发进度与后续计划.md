## 7. 约定提醒（写代码时必须遵守）

- **注释**：所有新文件都要 koroFileHeader 文件头；注释写「为什么」，禁止复述代码。
- **业务规则**：注释特定的东西解释业务妥协（如 `FileArchive.persistUriPermission` 解释为什么必须申请持久化授权）。
- **协程**：禁 `GlobalScope`；大循环插 `ensureActive()`；IO → `IoDispatcher`，分页 → `DefaultDispatcher` + `Mutex`。
- **大文件**：禁 `readText()` / `readBytes()`，一律流式（detekt `ForbiddenMethodCall` 会拦截）。
- **Compose**：参数只传数据 + lambda，动画用 `Animatable` + `graphicsLayer`，列表给稳定 key。
- **文档**：改了设计就要改 `docs/`，然后 `node scripts/build-archive.js` 重新生成根目录合并版与 HTML 版（**不要手改那两个生成产物**）。
